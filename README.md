# Grimoire for iPhone

A spellbook for D&D 2024 (5.5e) players of every class. It installs from Safari onto your
Home Screen, opens full screen and works offline.

Rules text: System Reference Document 5.2.1 by Wizards of the Coast LLC, CC-BY-4.0.
Grimoire is unofficial fan content, not approved or endorsed by Wizards of the Coast.
