# Grimoire full version for iPhone

Character sheet, spellbook, combat tracker, inventory, notes and companions for D&D 2024 (5.5e)
players of every class. It installs from Safari onto your Home Screen, opens full screen and works offline.
The app never rolls dice: you roll at the table and type in your results.

Version 2.3.0. Upload all files in this folder to a GitHub Pages repository (see "iPhone setup guide").

Rules text: System Reference Document 5.2.1 by Wizards of the Coast LLC, CC-BY-4.0.
